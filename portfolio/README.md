# Private portfolio staging

This folder contains a responsive English-language landing page in `index.html`. It is **not deployed publicly**.

[Open the HTML file on GitHub](./index.html) (to preview the rendered site, download/open the file locally or use a static server).

The site links to the five draft engineering project pages in the sibling `projects/` folder. Once reviewed, we can create an appropriately named standalone GitHub Pages repository or configure GitHub Pages as permitted by the account settings.

## Publication checklist
- [ ] Confirm individual contributions to FenRIR (association work; do not claim a teammate's contributions).
- [ ] Approve any borrowed FenRIR images and their attribution.
- [ ] Review personally taken tree-installation photographs and avoid internal laboratory schematics, source code or raw datasets.
- [ ] Upload approved Hestia and plotter photographs to the public media folder.
- [ ] Review the original GPA671 Python scripts before publishing any code.
- [ ] Update and approve CV link.
- [ ] Check permissions, complete mobile preview and get explicit approval before visibility changes / enabling Pages.

Do not expose this repository publicly before reviewing the content.
