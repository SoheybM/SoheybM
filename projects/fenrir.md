# FenRIR — French Robotics Cup 2026

**Collaborative robotics project | RIR — Robotique des Ingénieurs de Roanne, Polytech Lyon**

## Overview
FenRIR is an autonomous competition robot developed collectively by the **RIR association and its members** for the 2026 French Robotics Cup. Built for the *Winter is Coming* theme, it was designed to handle themed wooden game elements alongside the smaller Ratatosk PAMIs.

## Technical system
The existing RIR project documentation describes an ESP32 controller, LiDAR, stepper-motor drive, a vertical elevator, servos, pneumatic suction cups and auxiliary manipulator mechanisms. This reflects the **team's system**, not a claim that I built every subsystem.
